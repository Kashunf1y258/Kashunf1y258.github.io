I'm often asked about my development setup, so I thought I'd share the tools and configuration that help me be productive.

## Hardware

My primary development machine is a MacBook Pro with the M-series chip. The performance and battery life have been game-changing for mobile development work. I pair it with:

- External monitor for extended workspace when working from home
- Mechanical keyboard for comfortable typing during long sessions
- Quality headphones for focused work

## Software Stack

### Editor

I use **VS Code** as my primary editor with several essential extensions:

- GitHub Copilot for AI-assisted coding
- Prettier for consistent formatting
- ESLint for code quality
- Vim keybindings for efficient navigation

### Terminal

**iTerm2** with a custom zsh configuration powered by Starship prompt. I use **tmux** for session management and window splitting.

### Version Control

**Git** is essential for all my projects, paired with GitHub for hosting and collaboration. I follow conventional commit messages for clear changelog generation.

## Development Tools

I rely on several tools to streamline my workflow:

- **Docker** for containerization and consistent environments
- **Homebrew** for package management
- **Raycast** for quick access and automation
- **Obsidian** for note-taking and documentation

## Productivity Tips

Some habits that have improved my productivity:

1. Use keyboard shortcuts whenever possible
2. Keep terminal commands in muscle memory
3. Maintain a clean, organized workspace
4. Take regular breaks to avoid burnout
